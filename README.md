
# Tsadis Sorgu Bot




## Bu Nedir?

Botu ilk yaptığımda fazla etkileşim alıp ardından başıma bela açan bottur. Hiçbir sorumluluk almıyorum.
## Botu Çalıştırın

Projeyi indirin,

Proje dizinine gidin,

Klasöre Shift+Sağtık yaparak powershelli açın,

Gerekli paketleri yükleyin

```bash
  npm install
```

Botu çalıştırın

```bash
  node index.js
```
